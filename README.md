# AGG Software

Windows software for data acquisition since 1999. Our programs take the data that a scale, a meter, an analyser, a PLC, a GPS receiver or a PBX sends over RS-232, RS-485, USB, TCP/IP, MODBUS or OPC, and put it into a file, Excel, a database or another program, without code. Trial versions of every product are on [aggsoft.com](https://www.aggsoft.com/).

## Products

- [Advanced Serial Port Monitor](https://www.aggsoft.com/serial-port-monitor.htm) - terminal, port sniffer and MODBUS tester
- [Advanced Serial Data Logger](https://www.aggsoft.com/serial-data-logger.htm) - RS-232 and RS-485 data to files, Excel and databases, with parsers for hundreds of devices
- [Advanced TCP/IP Data Logger](https://www.aggsoft.com/tcpip-data-logger.htm) - the same for TCP and UDP sources
- [PBX Data Logger](https://www.aggsoft.com/pbx-data-logger.htm) - SMDR and CDR call records from several hundred PBX models
- [TCP COM Bridge](https://www.aggsoft.com/tcp-com/) - COM port to TCP/UDP redirector
- [OPC Data Logger](https://www.aggsoft.com/opc-data-logger.htm), [Advanced NMEA Data Logger](https://www.aggsoft.com/nmea-data-logger.htm), [Data Logger Suite](https://www.dataloggersuite.com/) and [more](https://www.aggsoft.com/)
